## 测试中发现并已修复的问题

1. **配置文件扩展名**：Xray 按扩展名识别配置格式，临时文件改为 `config.new.json`。
2. **ObservatoryService**：没有 `observatory` 段时启用它会导致 Xray 拒绝启动。现在只在存在 balancer 时开启。
3. **失败重试风暴**：下发失败后会被反复重试（产生了 199 个失败任务）。现在失败后 10 分钟内不自动重推。
4. **测速**：单次大文件下载被 Cloudflare 拒绝，测速结果为 0。改为多路分块、限时测速。
5. **回程路由**：把 traceroute 标题行里的目标 IP 误当成了一跳。
6. **SS2022 热添加**：入站启动时没有用户的话，添加用户会静默失败（`Added 0 user(s)`）。现在检测到后改为重启应用。
7. **面板地址**：面板下发的地址会覆盖 Agent 正在用的地址，地址不可达时 Agent 重启后连不回来。现在保留当前可用地址作为最后的备用。
8. **落地防火墙开关**：切换后不下发；离线期间的变更会丢失；线路页显示状态不准确。三处均已修复。
9. **内网互联**：落地新增「连接地址」，用于入口走内网的情况，此时白名单同时放行内网网段。位于 NAT / CGNAT 后的机器改为上报公网 IP。
10. **手机端表格**：滚动表格中的单元格不再逐字换行。
11. **内置脚本**：面板升级后，新增的内置脚本可以补入。
